About
#

A read-only Unreal Engine editor plugin that scans project assets and flags the small problems that quietly pile up: bloated materials, missing LODs, oversized textures, off-convention names, and plenty more. It surfaces findings in a sortable, filterable list with a project health score, and lets you export to CSV or a shareable HTML report.

Materials-first by design — because material debt is the most expensive to fix late. Every rule can be toggled, thresholds are adjustable, and settings persist per project.

Features
#

  • Materials: bloated masters, one-off masters, duplicate instances, unused parameters, direct-master-on-mesh
  • Meshes: missing LODs (skips tiny meshes), Nanite/LOD sanity, high vertex counts, missing collision or physics
  • Textures: oversized, non-power-of-two, never-stream, wrong LOD group. Reads authored size, not placeholder
  • Naming: per-type prefixes as a single source of truth
  • Sound, blueprint, and misc hygiene checks
  • CSV export (RFC-4180) and HTML export (self-contained report)
  • Platform presets (Mobile/VR, Console, PC) and named profiles
  • Cancellable scans with progress bar
  • Runs entirely on machine — no telemetry, no network calls

Notes

Built for UE 5.5. Source plugin — compiles on first build. MIT licensed.
